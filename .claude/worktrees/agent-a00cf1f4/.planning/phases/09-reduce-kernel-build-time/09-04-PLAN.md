1. Add a `[features]` section BEFORE the `[dependencies]` section:
```toml
[features]
default = []
gga = ["dep:libxc-kernel-gga"]
mgga = ["dep:libxc-kernel-mgga"]
all-kernels = ["gga", "mgga"]
```

2. Change the kernel-gga and kernel-mgga dependency lines to be optional:
```toml
libxc-kernel-gga = { path = "crates/kernel-gga", optional = true }
libxc-kernel-mgga = { path = "crates/kernel-mgga", optional = true }
```

3. Keep `libxc-kernel-lda` as a NON-optional dependency (always compiled).

4. Keep all other content exactly as-is (profile settings, workspace members, dev-dependencies).

5. The dev-dependencies for libxc-kernel-mgga-{1..37} should remain as-is (they are test deps, not affected by feature gating).

pub mod launch;
