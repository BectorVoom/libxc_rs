**Step 1: Create src/math/erf.rs** (per D-05, D-06 — Cephes/libm-style piecewise rational approximation):

Port the erf implementation from libm's `erf.c` (Cephes-derived). The function uses multiple intervals with different polynomial/rational coefficient sets:

Region breakdown (from libm source):
- |x| < 0.84375: Polynomial approximation `erf(x) = x + x * P(x^2)` where P is degree-4 polynomial
- 0.84375 <= |x| < 1.25: `erf(x) = erfc8_sa + P(x-1)/Q(x-1)` rational approximation
- 1.25 <= |x| < 2.857142857: `erfc(x) = exp(-x^2) * P(1/x)/Q(1/x)`; `erf(x) = 1 - erfc(x)`
- 2.857142857 <= |x| < 6.0: Similar with different coefficients
- |x| >= 6.0: `erf(x) = 1.0` (within f64 precision)

For the #[cube] implementation:
- Use nested `select()` calls for branchless region dispatch (per Pattern 2 from RESEARCH.md)
- Coefficients are f64 constants defined inline (not from Array, since they're compile-time known)
- Manually expand Horner evaluation inline for each region's polynomial (avoid Array overhead for small fixed-size coefficient sets)
- Implement `erfc_approx(x: f64) -> f64` as `1.0 - erf_approx(x)` for |x| < 2, and direct computation for larger |x| to avoid catastrophic cancellation

CRITICAL: The full set of coefficients from libm's erf.c must be used. These are ~30 named constants (pp0-pp4, qq1-qq5, pa0-pa6, qa1-qa6, ra0-ra7, sa1-sa8, rb0-rb6, sb1-sb7, erx). Copy them exactly from the libm source. Truncate to f64 precision (17 significant digits).

| Threat ID | Category | Component | Disposition | Mitigation Plan |
