**`pub fn dispatch_lda(input: &LdaInput, order: DerivativeOrder, output: &mut LdaOutput, alpha: f64, thresholds: &Thresholds) -> Result<(), LibxcRsError>`:**

1. Get `np = input.np()`, `spin = input.spin()`
2. Compute `dims = Dimensions::lda(spin)`
3. Create CubeCL client: `let client = cpu_client()`
4. Upload input: `let rho_handle = create_input_buffer(&client, input.rho())`
5. **Zero caller output buffers**: For each `Some(ref mut buf)` field in output, fill with 0.0 (`buf.fill(0.0)`)
6. Create CubeCL output handles. For each derivative level up to `order`:
   - If `output.<field>` is `Some`, create buffer sized `np * dims.<field> as usize` via `create_zero_output_buffer`
   - If `output.<field>` is `None`, still create a dummy buffer of the same size (kernel writes to it but results are discarded per Open Question 3 in RESEARCH.md)
   - For derivative levels ABOVE the requested order, no buffer needed (kernel doesn't write to them)
7. Calculate launch config: `let (cube_count, cube_dim) = calculate_launch_config(np)`
8. Match on `(order, spin)` to select the correct kernel. 10 arms total:
   - `(DerivativeOrder::Exc, Spin::Unpolarized)` -> `lda_x::lda_x_exc_unpol::launch_unchecked::<CpuRuntime>(&client, cube_count, cube_dim, ArrayArg::from_raw_parts::<f64>(&rho_handle, rho_len, 1), ArrayArg::from_raw_parts::<f64>(&zk_handle, zk_len, 1), ScalarArg::new(alpha), ScalarArg::new(thresholds.density), ScalarArg::new(thresholds.zeta))`
   - `(DerivativeOrder::Vxc, Spin::Unpolarized)` -> `lda_x::lda_x_vxc_unpol::launch_unchecked` with rho, zk, vrho handles
   - Continue for all 10 combinations (5 orders x 2 spins)
   - Each launch call is wrapped in `unsafe { ... }.unwrap()`
9. After kernel launch, read back results: For each derivative level up to `order`, if `output.<field>` is `Some(ref mut buf)`, call `read_output_buffer(&client, handle, buf.len())` and `buf.copy_from_slice(&result)`. If `None`, drop the handle (discard results).
10. Return `Ok(())`

**Key implementation detail for None output fields (D-07 bridge):**
When `output.zk` is `None` but order >= Exc, we still need to pass a valid CubeCL array to the kernel. Create a dummy buffer via `create_zero_output_buffer(&client, np * dims.zk as usize)`. After the kernel runs, do NOT read it back. This preserves the kernel's simple signature while supporting selective output.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dispatch -> CubeCL kernel | Validated bundles decomposed into raw buffer handles for unsafe kernel launch |
| kernel output -> caller buffers | Kernel results copied from device memory back into caller-provided mutable slices |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-03-04 | T (Tampering) | Output buffer zeroing | mitigate | Dispatch zeros caller output buffers before kernel launch; kernels use +=, so stale data would corrupt results |
| T-03-05 | E (Elevation) | unsafe kernel launch | accept | CubeCL requires unsafe for launch_unchecked; buffer sizes are validated at input/output construction time; bounds check in kernel |
| T-03-06 | D (DoS) | Dummy buffer allocation for None fields | accept | Allocating dummy buffers for None output fields is bounded by np*max_dim; acceptable overhead for correctness |
</threat_model>
