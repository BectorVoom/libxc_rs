MGGA kernel signature extends GGA with lapl and tau inputs + 70 total output fields:
```rust
// [EXPECTED PATTERN for MGGA kernels]
#[cube(launch_unchecked)]
pub fn mgga_x_tpss_vxc_unpol(
    rho: &Array<f64>,
    sigma: &Array<f64>,
    lapl: &Array<f64>,       // NEW: laplacian of density
    tau: &Array<f64>,        // NEW: kinetic energy density
    zk: &mut Array<f64>,
    vrho: &mut Array<f64>,
    vsigma: &mut Array<f64>,
    vlapl: &mut Array<f64>,  // NEW: only if functional uses laplacian
    vtau: &mut Array<f64>,   // NEW: only if functional uses tau
    // scalar params + thresholds
    dens_threshold: f64,
    zeta_threshold: f64,
    sigma_threshold: f64,
    tau_threshold: f64,      // NEW
) { ... }
```

MGGA output fields by derivative level (70 total):
- Exc: zk (1)
- Vxc: vrho, vsigma, vlapl, vtau (4)
- Fxc: v2rho2, v2rhosigma, v2rholapl, v2rhotau, v2sigma2, v2sigmalapl, v2sigmatau, v2lapl2, v2lapltau, v2tau2 (10)
- Kxc: 20 fields (v3rho3 through v3tau3)
- Lxc: 35 fields (v4rho4 through v4tau4)

Polarized MGGA dimensions (from Dimensions::mgga):
- lapl: 2, tau: 2
- vlapl: 2, vtau: 2
- v2rholapl: 4, v2rhotau: 4, v2sigmalapl: 6, v2sigmatau: 6, v2lapl2: 3, v2lapltau: 4, v2tau2: 3
- (higher orders grow combinatorially)

Conditional outputs: Not all MGGA functionals use laplacian. Check C source:
- If C code writes to `out->vlapl` -> functional uses lapl -> include vlapl output parameter
- If C code does NOT write to `out->vlapl` -> functional does not use lapl -> omit vlapl parameter
