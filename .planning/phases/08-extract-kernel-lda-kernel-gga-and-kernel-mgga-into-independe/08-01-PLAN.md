```toml
[package]
name = "libxc-kernel-math"
version = "0.1.0"
edition = "2024"

[profile.test]
```

3. Copy all 12 math source files from `src/math/` to `crates/kernel-math/src/`:
   - constants.rs, powers.rs, piecewise.rs, polynomials.rs, erf.rs, spin.rs,
     dft_quantities.rs, bspline.rs, lambert_w.rs, expint_e1.rs, special.rs, integrate.rs

4. Create `crates/kernel-math/src/lib.rs` with the same allow attributes as the main crate lib.rs (needed for CubeCL macro expansions) and all pub mod declarations:
```rust
#![allow(clippy::excessive_precision)]
#![allow(clippy::needless_late_init)]
#![allow(clippy::too_many_arguments)]

pub mod constants;
pub mod powers;
pub mod piecewise;
pub mod polynomials;
pub mod erf;
pub mod spin;
pub mod dft_quantities;
pub mod bspline;
pub mod lambert_w;
pub mod expint_e1;
pub mod special;
pub mod integrate;
```

5. In every copied math source file, replace any `use crate::math::` with `use crate::` since the math modules are now at the crate root. Grep first to check -- the research says math has zero `use crate::` imports, but verify by running: `grep -rn "use crate::" crates/kernel-math/src/`. If any are found that reference sibling math modules (e.g., `use crate::math::constants`), rewrite to `use crate::constants`.

6. Run `cargo check -p libxc-kernel-math` to confirm the crate compiles standalone.
