Create tools/translate_mgga.py by adapting tools/translate_gga.py with these MGGA-specific changes:

1. **LEVEL_OUTPUTS dict**: Extend from 15 GGA fields to 70 MGGA fields:
   - exc: ['zk']
   - vxc: ['zk', 'vrho', 'vsigma', 'vlapl', 'vtau']
   - fxc: add v2rholapl, v2rhotau, v2sigmalapl, v2sigmatau, v2lapl2, v2lapltau, v2tau2
   - kxc: add all 20 3rd-order MGGA cross-derivatives (v3rho2lapl, v3rho2tau, v3rhosigmalapl, v3rhosigmatau, v3rholapl2, v3rholapltau, v3rhotau2, v3sigma2lapl, v3sigma2tau, v3sigmalapl2, v3sigmalapltau, v3sigmatau2, v3lapl3, v3lapl2tau, v3lapltau2, v3tau3)
   - lxc: add all 35 4th-order MGGA fields (copy field names from 08-RESEARCH.md code example)

2. **POL_DIMS dict**: Extend with all 70 MGGA field polarized dimensions. Copy exact values from 08-RESEARCH.md MGGA_POL_DIMS table (already verified against verify/src/lib.rs).

3. **Function signature generation**: Add `lapl: &Array<f64>` and `tau: &Array<f64>` parameters after `sigma` in the generated Rust function signature.

4. **Input array translation in translate_line()**:
   - Unpol: `lapl[0]` -> `lapl[ip]`, `tau[0]` -> `tau[ip]`
   - Pol: `lapl[0]` -> `lapl0`, `lapl[1]` -> `lapl1`, `tau[0]` -> `tau0`, `tau[1]` -> `tau1`
   (Same pattern as rho and sigma already use in translate_gga.py)

5. **Polarized input loading block**: After the sigma0/sigma1/sigma2 loading block, add:
   ```rust
   let lapl0 = lapl[ip * 2];
   let lapl1 = lapl[ip * 2 + 1];
   let tau0 = tau[ip * 2];
   let tau1 = tau[ip * 2 + 1];
   ```
   For unpol, no explicit loading needed (lapl[ip] and tau[ip] used inline).

6. **Output guard pattern handling**: The parser must handle all 4 MGGA guard patterns:
   - Pattern A: `if(out->zk != NULL)` -- standard (same as GGA)
   - Pattern B: `if(out->vrho != NULL && ... XC_FLAGS_NEEDS_LAPLACIAN ...)` -- lapl fields
   - Pattern C: `if(out->vrho != NULL && ... XC_FLAGS_NEEDS_TAU ...)` -- tau fields
   - Pattern D: `if(out->v2rho2 != NULL && ... NEEDS_LAPLACIAN ... NEEDS_TAU ...)` -- both
   All patterns produce the same translated output: unconditional `field[ip * dim + N] += tvar;`
   The guard itself is stripped because the Rust kernel is specialized per derivative order.

7. **CLI interface**: Same as translate_gga.py:
   `translate_mgga.py <c_file> <func_name> --write-to <dir> [--vxc-only]`

8. **Source directories**: `libxc-master/src/maple2c/mgga_exc/` (90 files) and `libxc-master/src/maple2c/mgga_vxc/` (2 files: mgga_x_2d_prp10.c, mgga_x_tb09.c).

Keep the same code structure as translate_gga.py: read_c_source, extract_function_bodies, translate_line, parse_body, generate_function_signature, write_module, main. Do NOT import from translate_gga.py -- make it self-contained.
