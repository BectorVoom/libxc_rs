<objective>
Add Cargo feature gates for kernel families so developers can build only the kernel families they need, reducing default build time from ~70 min (all kernels) to ~4 min (LDA only).

Purpose: During development, most work only requires LDA kernels. Compiling all 3.7M lines of GGA + MGGA kernel code wastes 60+ minutes per build. Feature gates let developers opt in to heavier families only when needed.

Output: Feature-gated dependencies in root Cargo.toml, kernel-mgga facade, and kernel-gga facade. Conditional compilation in src/kernel/mod.rs and facade lib.rs files.
</objective>


```toml
libxc-kernel-math = { path = "crates/kernel-math" }

libxc-kernel-mgga = { path = "crates/kernel-mgga", optional = true }
```

The `lda` feature is a marker only (kernel-lda is always compiled as it is small at 182K lines / 3.5 min). The hierarchy is: `mgga` implies `gga` implies `lda`. `all-kernels` is an alias for `mgga` (can be extended later for hybrids etc).
