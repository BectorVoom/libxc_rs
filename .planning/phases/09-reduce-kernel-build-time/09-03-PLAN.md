  <action>
Edit the workspace root `Cargo.toml` to add `incremental = true` to both `[profile.dev]` and `[profile.test]` sections. This consolidates the incremental setting that was previously scattered across sub-crate files.

The profile sections should become:

```toml
# Reduce peak memory: CubeCL proc macro expansion generates massive IR.
# Workspace-wide profile: debug=0 skips LLVM debug scope tracking,
# codegen-units=16 bounds per-unit memory at the cost of less parallelism.
# incremental=true speeds up iterative dev rebuilds (sccache was removed
# because it cannot cache incremental builds).
[profile.dev]
debug = 0
codegen-units = 16
incremental = true

[profile.test]
debug = 0
codegen-units = 16
incremental = true
```

Do NOT modify `[package]`, `[dependencies]`, `[dev-dependencies]`, `[workspace]`, or `[features]` sections.
