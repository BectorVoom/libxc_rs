<objective>
Re-split all 131 GGA functionals into ~22 sub-crates using first-fit-decreasing bin packing to ~50K lines per crate, following the proven MGGA 37-sub-crate pattern. The 25 previously-deferred functionals get derivative-order feature gates on their oversized kxc/lxc modules to prevent OOM during CubeCL proc macro expansion.

Purpose: The current 3 GGA sub-crates have 35-36 functionals each (144K-175K lines), which is 3x too large for efficient parallel compilation. Re-splitting to ~22 crates enables parallel builds and matches the working MGGA pattern.

Output: 22 new kernel-gga-{1..22} sub-crates, updated facade, updated workspace members.
</objective>

  <action>
Create `tools/resplit_gga.py` -- a Python script that automates the entire GGA sub-crate re-split. The script MUST:

**Step 1: Inventory and bin-pack**
- Walk `crates/kernel-gga/src/` to find all 131 functional directories (each containing mod.rs + per-level .rs files)
- Compute total lines per functional (sum of all .rs files in the directory)
- Identify the 25 deferred functionals by checking if any file named `lxc_pol.rs` or `kxc_pol.rs` exceeds 5000 lines
- Sort functionals descending by line count
- Apply first-fit-decreasing bin packing with BIN_LIMIT = 50000
- Print the bin assignments as a summary

**Step 2: Delete old sub-crates**
- Remove `crates/kernel-gga-1/`, `crates/kernel-gga-2/`, `crates/kernel-gga-3/` directories entirely (these contain COPIES of sources already in kernel-gga/src/)

**Step 3: Create new sub-crates**
For each bin N (1 to ~22):
- Create `crates/kernel-gga-N/` directory
- Create `crates/kernel-gga-N/src/` directory
- For each functional in bin N: COPY (not move -- keep canonical source in kernel-gga/src/) the functional directory from `crates/kernel-gga/src/{functional}/` to `crates/kernel-gga-N/src/{functional}/`
- If the sub-crate contains ANY deferred functional, the mod.rs for EACH deferred functional in that crate must be rewritten to add `#[cfg(feature = "order-kxc")]` before `pub mod kxc_unpol;` and `pub mod kxc_pol;`, and `#[cfg(feature = "order-lxc")]` before `pub mod lxc_unpol;` and `pub mod lxc_pol;`
- Generate `crates/kernel-gga-N/Cargo.toml`:
  ```toml
  [package]
  name = "libxc-kernel-gga-N"
  version = "0.1.0"
  edition = "2024"

  [features]            # ONLY if crate has deferred functionals
  order-kxc = []
  order-lxc = ["order-kxc"]
  all-orders = ["order-lxc"]

  [dependencies]
  cubecl = { version = "0.9.0", default-features = false, features = ["cpu"] }
  libxc-kernel-math = { path = "../kernel-math" }
  ```
  (Omit the [features] section entirely for crates with NO deferred functionals)
- Generate `crates/kernel-gga-N/src/lib.rs`:
  ```rust
  #![allow(clippy::excessive_precision)]
  #![allow(clippy::needless_late_init)]
  #![allow(clippy::too_many_arguments)]

  //! GGA kernel translations batch N.

  pub mod functional_name_1;
  pub mod functional_name_2;
  ```

**Step 4: Update facade**
- Rewrite `crates/kernel-gga/Cargo.toml`:
  - Dependencies: all N sub-crates as path deps, plus cubecl and kernel-math
  - [features] section that forwards order-kxc/order-lxc to ALL sub-crates that have those features
- Rewrite `crates/kernel-gga/src/lib.rs`:
  - `pub use libxc_kernel_gga_N as batchN;` for each sub-crate
  - Remove the 25 commented-out `// pub mod` entries
  - Remove the `pub mod deferred;` line if present
  - Keep the three `#![allow(...)]` attributes

**Step 5: Update workspace**
- Read `Cargo.toml`, find the `[workspace] members = [...]` array
- Remove old entries: "crates/kernel-gga-1", "crates/kernel-gga-2", "crates/kernel-gga-3"
- Add new entries: "crates/kernel-gga-1" through "crates/kernel-gga-N"
- Write back Cargo.toml (preserve all other content exactly)

**Important details:**
- The script must be idempotent -- if run again, it produces the same result
- Use `shutil.copytree` for copying functional directories
- When rewriting deferred functional mod.rs files, read the original, find lines matching `pub mod kxc_unpol;` etc., and prepend the `#[cfg(feature = "...")]` attribute
- Sort functional names alphabetically within each bin's lib.rs for consistency
- The script should print a summary showing: bin count, functionals per bin, total lines per bin, which bins have feature gates

**Run the script after writing it:**
```bash
python3 tools/resplit_gga.py
```
