<objective>
Batch re-translate ALL kernel crates using the modified translators from Plan 01,
then verify every functional against the libxc oracle at 1e-12 to 1e-13 tolerance.

Purpose: Plan 01 proved the incremental derivative + shared preamble approach on
single proof-of-concept functionals. This plan applies it to all 649 functionals
across LDA, GGA, and MGGA families, achieving the actual build time reduction.

Expected code volume reduction:
- LDA: 182K lines -> ~80K lines (~56% reduction)
- GGA: 1.6M lines -> ~600K lines (~62% reduction)
- MGGA: 2.0M lines -> ~700K lines (~65% reduction)
- Total: 3.7M -> ~1.4M lines (~62% reduction)

Expected build time reduction:
- Proc macro expansion is superlinear in function size
- Splitting 56K-line functions into 5-10K chunks should yield 5-10x speedup per crate
- Conservative estimate: full build from ~70 min to ~15-25 min

Output: All kernel crates re-translated and verified.
</objective>
