## Why a replan, not another quick task

Phase 11 has been chasing structural metrics — file counts, dispatch shape, launch budget, audit gates — while never compiling the resulting tree. Plans 11-01 / 11-02 / 11-03 all declared structural success without per-`-p` cargo gates. 11-04 was designed as the first per-`-p` compile gate, and it surfaces a layered architectural incompatibility. Each layer fixes the next; layer 4 lives in code the q01 brief explicitly carved out as out-of-scope. Continuing to grind through layers reveals new bug families instead of unblocking. The right move is a planner-level reset.

The replan should establish a **compile-first entry gate**: one canary kernel compiles end-to-end + 1e-12 parity vs libxc oracle, under CubeCL 0.10. Once that anchor holds, the rest of Phase 11 (regen, per-`-p` sweep, audits) is mechanical.
