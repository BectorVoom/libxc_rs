    ```python
        body_lines: tuple[str, ...]
        inputs: tuple[str, ...]
        outputs: tuple[str, ...]
        bool_inputs: tuple[str, ...] = ()

    def reverse_dep_counts(compute_lines: list[str]) -> dict[str, int]: ...

    def partition_into_chunks(
        compute_lines: list[str],
        var_deps: dict[str, set[str]],
        chunk_max_lines: int,
        *,
        min_uses: int = DEFAULT_MIN_USES,
        min_chain_length: int = DEFAULT_MIN_CHAIN_LENGTH,
        max_input_arity: int = DEFAULT_MAX_INPUT_ARITY,
        max_output_arity: int = DEFAULT_MAX_OUTPUT_ARITY,
        force_headroom: int = DEFAULT_FORCE_HEADROOM,
    ) -> list[Chunk]:
        ...
    ```

    Implementation contracts (each enforced by an emit-side `assert` in cse.py):

    - **Determinism contract:** same `(compute_lines, var_deps)` always returns the same chunk list. Sort all set iterations; never rely on hash-derived ordering. (P11-INV-6)
    - **Coverage contract:** `sum(len(c.body_lines) for c in result) == len(compute_lines)`; no line lost or duplicated.
    - **Size contract:** every `len(c.body_lines) <= chunk_max_lines`.
    - **Arity contracts:** every `len(c.inputs) <= max_input_arity`, `len(c.outputs) <= max_output_arity`. On overflow, raise `ChunkArityError` with the offending count + the chunk index.
    - **Flat-graph contract:** chunks never reference symbols defined in another chunk except via `inputs`. Outputs sorted by first-def line index.
    - **Forced-breakpoint rule:** when chunk size reaches `chunk_max_lines - force_headroom` without a natural breakpoint, scan the next `force_headroom` lines for the cut point that minimizes `len(inputs) + len(outputs)` and force a break there.
    - **Bool detection:** if any RHS contains a literal `<= >= < > == !=` operator, the LHS is a bool. Bools listed in `Chunk.bool_inputs` — emitter re-derives in the consuming chunk rather than tuple-pass.
