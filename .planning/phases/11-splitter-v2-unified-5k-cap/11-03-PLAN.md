GGA-specific ext_param shape: GGA functionals have `sigma` arrays in addition to `rho`. The wrapper signature shape is:

```rust
#[cube]
pub fn {wrapper}<F: Float>(
    rho: &Array<F>, sigma: &Array<F>,
    {output_buf}: &mut Array<F>,
    {param}: f64, ...,
    dens_threshold: f64, sigma_threshold: f64,
) { ... }
```

Inside the body, the wrapper unpacks `let rho0 = rho[ip*2]; let rho1 = rho[ip*2+1]; let sig0 = sigma[ip*3]; let sig1 = sigma[ip*3+1]; let sig2 = sigma[ip*3+2];` then dispatches to chunks. Chunks consume the unpacked rho/sigma values via tuple inputs (NOT the buffers themselves — D-02 forbids passing `&Array<F>` to chunks; only the wrapper holds buffers).

Routing-aware cube_attr (existing GGA logic at translate_gga.py — verify the line) — chunks always plain `#[cube]`; wrapper retains routing-aware decision (split helpers always plain `#[cube]`).
