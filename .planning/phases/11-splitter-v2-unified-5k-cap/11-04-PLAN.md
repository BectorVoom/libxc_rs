## What the First Pause Blocked (Option A Path — CLOSED)

**Context:** 2026-05-18 discussed two options for D-02 (how to handle <F: Float> chunks calling concrete-f64 helpers):

**Option A (attempted, failed, NOW CLOSED):**
- **Approach:** Refactor all 38 helpers in `crates/kernels/math/src/` to generic over `<F: Float>`
- **Motivation:** Simplest ABI — chunks call generic helpers directly with no wrapping
- **Attempt:** Automatic refactoring script (Phase 2 style) + manual fixes
- **Result:** Systematic errors in 11 files (helper signatures, internal literals, named constants)
- **User decision:** Too many systematic errors, too high risk of manual fixes introducing new bugs
- **Status:** ABANDONED. Commit dcb7d517d marks the attempted work.

**Why Option A failed:**
- Automated Phase 2 refactoring patterns (built for simpler transformations) don't generalize to helpers with 4-6 internal f64 literals each
- 38 helpers × 4 internal literals per helper ≈ 152 literal-wrap sites
- Named constants (M_PI, M_CBRT3, ...) require definition-site wrapping; translators produce them
- Manual fixing 11 files introduces new risk (human error, missed edge cases)

## What the Pivot Unlocks (Option C Path — LOCKED 2026-05-18)

**Option C (locked 2026-05-18, operationalized in 11-05..08):**
- **Approach:** Preserve concrete-f64 helpers unchanged. Add call-site casting in the translator.
- **Where:** `tools/translate_v2/cse.py` (the CSE emit-pass that outputs tuple-returning chunks)
- **What:** When a `<F: Float>` chunk calls a concrete-f64 helper, wrap the call:
  - `helper_f64(x)` → `cast_into_f(helper_f64(cast_from_f(x)))`
  - `cast_from_f` and `cast_into_f` are CubeCL-compatible inline helpers (part of chunk signature)
  - Zero-cost abstraction — casts inline to temporaries, no actual bit-conversion overhead
- **Scope:** ~5–7 call patterns across 581K auto-generated call sites (but generated, not hand-written)
- **Benefit:** 
  - Preserves `crates/kernels/math/src/` unchanged (lower risk than Option A)
  - Generated code boilerplate acceptable for this phase
  - Simpler tooling change (translator-level, not global refactor)
- **Status:** LOCKED. Plans 11-05..08 operationalize this.
