**Call site wrapping (Option C pattern):**
Instead of refactoring helpers to generic, translator emits:
```rust
// In generated chunk (F-typed):
let result: F = cast_into_f(pow_1_3(cast_from_f(x)));
```

These cast helpers (`cast_from_f`, `cast_into_f`) are zero-cost abstractions in CubeCL and preserve f64 semantics while allowing F-typed chunks to call f64 helpers without hand-editing helpers.

mod test_cast_call_site {

    use libxc_kernel_math::*;

    #[cube]
    pub fn test_pow_cast<F: Float>(x: F) -> F {
        // Pattern validation: F-typed input, f64 helper, F-typed output via cast
