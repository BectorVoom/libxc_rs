**Implementation:**

1. **Create LiteralWrapper in cse.py:**
   ```python
   class LiteralWrapper:
       """Wraps all f64 literals as F::new(literal) for generic <F: Float> chunks."""
       
       def __init__(self, chunk_body_str: str):
           self.body = chunk_body_str
       
       def wrap_literals(self) -> str:
           """Apply F::new wrapping to all numeric literals."""
           import re
           
           # Pattern 1: Decimal literals (1.23, 0.5, etc.)
           body = re.sub(r'\b(\d+\.\d+(?:[eE][+-]?\d+)?)\b', r'F::new(\1)', self.body)
           
           # Pattern 2: Integer-mantissa (2e-21, 1e10, etc.)
           body = re.sub(r'\b(\d+[eE][+-]?\d+)\b', r'F::new(\1)', body)
           
           # Pattern 3: Named constants (M_PI, M_CBRT3, etc.)
           named_constants = {'M_PI', 'M_CBRT2', 'M_CBRT3', 'M_CBRT4', 'M_SQRT2', 
                            'M_SQRT3', 'M_PI_OVER_2', 'M_2_PI', 'M_SQRT_PI', 'M_SQRT_2PI',
                            'M_CBRT_HALF', 'M_INV_SQRT2', 'M_INV_SQRT3'}
           for const_name in named_constants:
               body = re.sub(rf'\b{const_name}\b(?!.*::)', rf'F::new({const_name})', body)
           
           return body
   ```

2. **Integration into translate_one_function flow (translate_mgga.py, translate_gga.py, translate_lda_v2.py):**
   - After split_by_output_array + merge_small_splits
   - If chunk is still > chunk_max_lines, apply CSE chunking
   - Before emitting chunk body, run `LiteralWrapper(body).wrap_literals()`
   - Emit chunk as `#[cube] fn chunk_NN<F: Float>(…) -> (F, F, ...)` with wrapped body

3. **Retire `_wrap_f64_literals` regex from per_functional.py:**
   - Delete the regex and related function
   - Update any per_functional.py emit calls to use the AST visitor instead
