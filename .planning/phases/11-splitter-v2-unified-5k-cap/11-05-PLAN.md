### Math Helpers: Refactored to Generic (Option A)

All 38 functions across 16 files are now generic. Below is the transformation pattern applied uniformly.

**Before (concrete f64):**
```rust
#[cube]
pub fn pow_1_3(x: f64) -> f64 { … }
```

**After (generic <F: Float>):**
```rust
#[cube]
pub fn pow_1_3<F: Float>(x: F) -> F { … }
```

**Transformation rules applied by `tools/refactor_helpers_generic.py`:**
1. Function signatures: `fn name(x: f64) -> f64` → `fn name<F: Float>(x: F) -> F`
2. Method calls: `f64::method(x)` → `F::method(x)`
3. Literals: `1.0`, `0.0` → `F::new(1.0)`, `F::new(0.0)`
4. Named constants: left as `const NAME: f64 = VALUE` (no wrapping in const context — D-08 loads these at runtime)

**Known syntax errors from automated pass (11-06 D-18 fix scope):**
1. Function signature malformations — missing `(`, `param: f64` where should be `param: F`
2. Numeric literal errors — incomplete exponents (`0.123e-` instead of `0.123e-4`), malformed loop constructs
3. CubeCL 0.10 API drift in `#[cfg(test)]` blocks — `ArrayArg::from_raw_parts` signature changed (~165 test-only errors)

Files with errors: primarily the 11 automated-pass files (bessel, br89, bspline, deferred, dft_quantities, erf, expint_e1, integrate, mbrxc, special). The 5 manual-pass files (powers, piecewise, lambert_w, polynomials, spin) are clean.

Create `tools/refactor_helpers_generic.py` — a regex-based bulk transformer. The script:

1. Accepts a list of file paths (or globs) as arguments
2. For each file, applies these transformations in order:
   a. Function signatures: `fn (\w+)\(` → `fn $1<F: Float>(` (when return type is `-> f64`)
   b. Parameter types: `: f64` → `: F` (in function parameter position)
   c. Return types: `-> f64` → `-> F` (in function signature position)
   d. Method calls on f64 type: `f64::(\w+)\(` → `F::$1(`
   e. Numeric literals in expression position: `(\s)([\d]+\.[\d]*)(\s|[,;)])` → `$1F::new($2)$3`
   f. Named constants: SKIP lines matching `const [A-Z_]+: f64 =`
3. Writes changes back in place
4. Reports a summary: files changed, function counts, transformations applied

Apply the script to all 11 files. Then run a cleanup sed pass for edge cases the script misses.
