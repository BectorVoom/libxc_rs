   `impl<T: ScalarArgSettings> LaunchArg for T`):
   - 0.9 STALE: `ScalarArg { elem: $ctx.dt }` (and `ScalarArg { elem: $scalar_u }`)
   - 0.10 TARGET: `$ctx.dt` (and `$scalar_u`) — pass the bare f64/value; NO `ScalarArg { elem: ... }`
     wrapper. The 11-09 canary imports ZERO `ScalarArg` and passes `DENS_THRESHOLD`, `PARAM_CAB`, etc.
     as bare args.

3. **Launch return — `()`, drop the Result-chain:**
   - 0.9 STALE: `$kernel::launch_unchecked::<CpuRuntime>( ... ).map_err(map_launch_err)?;`
     (also any `.unwrap()` / `.expect()`)

     remove the `.map_err(map_launch_err)?` / `.unwrap()` / `.expect()` tail. (If `map_launch_err`
     becomes unused after this, leave it — `#![allow(unused)]` is already present in these files; do
     NOT chase warnings.)

4. **Import — delete the `ScalarArg` use:**
   - DELETE `use cubecl::frontend::ScalarArg;` from every file that has it. Do not replace it with
     another path — there is no `frontend::ScalarArg` in 0.10; scalars pass bare (transform 2).
