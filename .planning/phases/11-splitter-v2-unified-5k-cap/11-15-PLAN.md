### The exact 0.9 → 0.10 transformations (apply to all 5 files)

1. **ArrayArg (50 sites):** `ArrayArg::from_raw_parts::<f64>(&h, n, 1)` → `ArrayArg::from_raw_parts(h, n)`.
   - DROP the `::<f64>` turbofish.
   - DROP the 3rd (vectorization `1`) arg.
   - DROP the `&` — the handle is passed BY VALUE in 0.10 (was by reference in 0.9).
   - For an OUTPUT handle that is read back via `read_one` AFTER the launch, pass `h.clone()` (cheap
     Arc bump; the original survives for the read-back) — mirror launch.rs:152. For INPUT handles that
     are NOT read after launch, move by value (no clone) — mirror launch.rs:151.

2. **launch_unchecked (~13 sites):** the trailing `.unwrap()` on `*_kernel::launch_unchecked::<CpuRuntime>(...).unwrap();`
   → drop it: `*_kernel::launch_unchecked::<CpuRuntime>(...);`. In 0.10 launch_unchecked returns `()`.

3. **read_one (19 sites):** `let bytes = client.read_one(h);` →
   `let bytes = client.read_one(h).expect("read_one failed during output buffer read-back");`.
   In 0.10 read_one returns a Result; mirror launch.rs:81-83 exactly (same .expect string).
