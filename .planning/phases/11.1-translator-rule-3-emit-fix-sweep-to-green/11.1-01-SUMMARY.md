## Decisions Made

- **D-15 implementation: pure-regex emit pipeline.** The 5-step pipeline in `_wrap_f64_literals_v2` uses regex for every position dimension. The AST classifier (`classify_position`) is part of the public surface and is unit-tested but is not invoked per-token inside the emit fn. Trade-off: keeps the per-chunk emit cost low while pinning the taxonomy via pytest fixtures. Future maintainers can opt into a per-token AST walk if a new P-class needs it.
- **D-10 line 367 NUANCE codification.** The literal reading of CONTEXT.md D-10 ("FIXING the current ::<f64> emit at per_functional.py:367") would have produced incorrect code — the wrapper at that site is concrete-f64 (Array<f64> typed buffers). The actual fix lives inside `_wrap_f64_literals_v2`'s `_CHUNK_TO_CHUNK_CALL_RE` pass and operates on chunk-to-chunk calls INSIDE generic chunk bodies. The wrapper-side `::<f64>` stays. Inline comment at the emit site documents the divergence.
- **D-17 mechanism: delete outright + marker comment.** Block A reduced to name-remap only; Block B deleted entirely. Marker comments left in place explain the supersession with back-refs.
