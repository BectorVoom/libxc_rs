## What was done (significant deviations — all user-approved 2026-05-22)

### G3 — PASS (rewritten as a standalone direct-call canary)

The plan ran G3 via `verify/tests/parity_phase11.rs::phase11_worst_case` → `dispatch_mgga`.
Investigation found this **hollow and wasteful**: it built all 281 kernels (umbrella dep; OOMs at
jobs=3) yet never evaluated b94 (deferred/unrouted → `SkipNotRouted`; entry hard-coded id 568, real
id is 397). See memory `project_g3_b94_hollow_gate`.

**Rewrite:** new `verify-canary/` crate (workspace member, not default-members) depending on only
`libxc-kernel-mgga_c_b94` + cubecl(cpu) + libxc-sys. Launches the kernel directly via a thin
`#[cube(launch_unchecked)]` wrapper, compares `zk` to the libxc id=397 oracle. **Builds ONE kernel.**

**Verdict: G3 PASS — 4/4 grid points at 1e-12 (max rel_err 6.302e-13).** See 11.1-03-G3-PARITY-LOG.md.

### Point-0 root-cause deep-dive (user-requested) → von Weizsäcker τ-clamp

First run: pt1/2/3 matched to ~1e-13, pt0 (rho=0.1) diverged 2.3%. Decisive investigation:
- **BR89 exonerated** — libxc `xc_mgga_x_br89_get_x(+0.135) = 2.0493763822653`, identical to the
  kernel and a high-precision reference. The 60×-unroll Brent is correct.
- A pure-Rust port of the kernel formula reproduced the kernel's pt0 value **exactly** → faithful
  maple2c translation, no Rule-3-emit defect.
- **Root cause: the kernel omits libxc's von Weizsäcker τ-clamp `τ ≥ σ/(8ρ)`** (applied by libxc's
  `work_mgga` driver, not the maple2c expression). pt0 was the only point with τ < τ_W. Confirmed
  on 4 distinct τ<τ_W points (raw errors 4e-3…2.3e-2 → all ~5e-13 once clamped). Memory:
  `project_translator_missing_workmgga_tau_clamp`.

**Fix applied** in the canary host driver (`tau_von_weizsacker`), mirroring libxc's input
preprocessing. The **production** dispatch still lacks this regularization — SYSTEMIC MGGA gap,
handed to re-opened Phase 11.

### G4 — DEFERRED to Phase 11

G4 inherently requires building all 281 kernels (it sweeps all 649 functionals through dispatch),
which OOMs / is multi-hour on this 30 GB box — the same infeasibility class as the already-deferred
idempotency proof. Also, a meaningful G4 would be dominated by the τ_W work-driver gap above
(widespread MGGA τ<τ_W failures that aren't f32-precision issues). Deferred per
11.1-03-G4-DEFERRAL.md.
