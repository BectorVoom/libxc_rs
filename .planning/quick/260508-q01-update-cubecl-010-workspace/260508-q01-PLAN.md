# Quick Task 260508-q01: Update cubecl to 0.10.0

## Goal

Replace `cubecl = { version = "0.9.0" ... }` with `cubecl = { version = "0.10.0" ... }` in all
workspace Cargo.toml files, then regenerate Cargo.lock.

## Scope

- `/Cargo.toml` (root)
- `/crates/*/Cargo.toml` (~170 kernel crates)
- `/verify/Cargo.toml`
- No changes to `xtask/Cargo.toml` or `libxc-sys/Cargo.toml` (no cubecl dependency there)

## Tasks

### Task 1: Mass-replace cubecl version in all Cargo.toml files

**Files:** All Cargo.toml files containing `cubecl = { version = "0.9.0"`
**Action:** `sed -i` replace `cubecl = { version = "0.9.0"` → `cubecl = { version = "0.10.0"`
**Verify:** `grep -rn 'cubecl.*0.9.0' --include='Cargo.toml'` returns zero matches
**Done:** All Cargo.toml files show `cubecl = { version = "0.10.0"`

### Task 2: Regenerate Cargo.lock

**Files:** Cargo.lock
**Action:** `cargo update -p cubecl` to pull 0.10.0 lock entries
**Verify:** `grep 'name = "cubecl"' Cargo.lock` shows version 0.10.0
**Done:** Cargo.lock updated with cubecl 0.10.0 entries
