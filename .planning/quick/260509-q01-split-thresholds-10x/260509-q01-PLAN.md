# Quick Task 260509-q01 — Split thresholds × 10

## Goal

Bump `TARGET_MAX` (per-sub-crate bin-packing budget) from 50,000 lines to
500,000 lines in every splitter tool that still uses 50K, then execute each
splitter once so the tree reflects the new budget.

Two tools (`tools/resplit_gga.py`, `tools/rebatch_mgga.py`) are already at
`500_000`; they are unchanged.

## Caveats accepted by user

- `tools/split_oversized_kernel.py` carries an explicit comment that the 50K
  budget "stays as-is per CONTEXT D-09 (sub-crate re-bin-packing is OUT of
  scope for Phase 9)". The user is overriding that decision.
- 3 splitters hard-code `WORKSPACE = "/workspace"`, which does not exist on
  this host; they are patched to use the repo-relative `REPO_ROOT` pattern
  used by the other splitters.
- Most splitters short-circuit on the current tree (already split / no
  functional > 500K), so the re-run will be a near-no-op. That is OK — the
  contract is "constants bumped + tools executed".
