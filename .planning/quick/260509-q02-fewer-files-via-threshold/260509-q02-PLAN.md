# Quick Task 260509-q02 — Fewer files via bigger threshold

## Goal

Reduce the per-functional `.rs` file count across the kernel-* sub-crates by
allowing each `#[cube]` function file to hold more lines before the translator
splits it.

| Constant | Tools | Old | New | Effect |
|----------|-------|-----|-----|--------|
| `SPLIT_THRESHOLD` (per-cube-fn line cap) | `translate_lda_v2.py`, `translate_gga.py`, `translate_mgga.py` | 18,000 | 50,000 | ≈2.8× ⇒ most small/medium functionals collapse to 1 file each; only the truly large ones (`mgga_x_br89_explicit`, `lda_c_pk09`) keep multi-file splits |
| `regen_phase09.py` `threshold` default + `# Threshold:` log header | `regen_phase09.py` | 18,000 | 50,000 | Lockstep: GGA family otherwise gets stale 18K via `--split-threshold` |

`TARGET_MAX` is **not** changed — it stays at 500,000 (q01 state). Sub-crate
count is not affected by this task; only per-functional file count.
