# Quick Task 260509-q03 — Summary

## What was built

`tools/maple_to_kernels.py` — a thin orchestrator wrapping the existing
maple2c→Rust kernel pipeline behind one CLI:

```
tools/maple_to_kernels.py [--dry-run]
  translate --family {lda|gga|mgga|all} [--split-threshold N]
  split     --family {lda|gga|mgga|all} [--target-max N]
  all       --family {lda|gga|mgga|all} [--split-threshold N] [--target-max N]
```

Defaults pin current repo state: `SPLIT_THRESHOLD=100000`, `TARGET_MAX=500000`.

## Splitting-criteria semantics (preserved in module docstring)

- Larger `--split-threshold` ⇒ FEWER per-functional `.rs` files.
- Larger `--target-max` ⇒ FEWER sub-crates.
- User-direction memo: "fewer files / less aggressive splitting" ⇒ RAISE values.

## Wrapped tools (no logic reimplemented)

- Translators: `translate_lda_v2.py`, `translate_gga.py`, `translate_mgga.py`
- Splitters: `split_lda_subcrates.py`, `split_oversized_kernel.py {lda|gga|mgga}`

## CLI-gap warnings (papered-over, not fixed)

- LDA translator does not accept `--split-threshold` → warn + delegate; user
  must edit `SPLIT_THRESHOLD` in `tools/translate_lda_v2.py` directly to
  change LDA behavior.
- GGA/MGGA splitter (`split_oversized_kernel.py`) does not accept
  `--target-max` → warn + delegate; user must edit `TARGET_MAX` in
  `tools/split_oversized_kernel.py` directly to change those splits.

These gaps are documented in the driver docstring and surfaced as runtime
warnings, not silently swallowed.

## Smoke-test evidence

Three dry-run permutations exercised end-to-end (no real translation/split
performed; only command emission verified):

1. `all --family all --split-threshold 100000 --target-max 500000`
   → 3 translate cmds + 3 split cmds in correct order, all with `--dry-run`
   propagated to splitters. No warnings (defaults).
2. `split --family gga --target-max 250000`
   → expected WARN about GGA splitter ignoring `--target-max`; emits
   `split_oversized_kernel.py gga --dry-run`.
3. `translate --family lda --split-threshold 50000`
   → expected WARN about LDA translator ignoring `--split-threshold`; emits
   `translate_lda_v2.py --batch --write-to crates/kernel-lda/src/funcs`.

Help output rendered cleanly for top-level + each subcommand.
