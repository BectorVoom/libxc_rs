# Quick Task 260509-q04 — Summary

## What changed

`tools/split_lda_subcrates.py` gained a `--repack` mode (commit `13ad2313`),
then was used to consolidate LDA from 4 → 2 sub-crates (commit `a8fe9020`).

## Tool change (`13ad2313`)

`split_lda_subcrates.py` was previously split-only and idempotent. New
`--repack` flag opts INTO consolidation:

1. Detect every `kernel-lda-N` sub-crate.
2. `mv` each per-functional dir back into `kernel-lda/src/`.
3. `rm -rf` the now-empty sub-crate directories.
4. Re-run the existing bin-packer at the requested `--target-max`.
5. Strip stale entries from workspace `Cargo.toml`; emit fresh ones.
6. Rewrite `kernel-lda/src/lib.rs` re-exports and `kernel-lda/Cargo.toml`
   `[dependencies]` for the new bin count.

`--dry-run` works for `--repack` too (scans both `kernel-lda/src/` and
each `kernel-lda-N/src/` so the bin-pack accounting matches a live run).
