## Tool changes (commits `cb85f3a5`, `5708902a`)

Both tools previously had a fundamental gap: when `split_oversized_kernel.py`
or `split_oversized_mgga.py` had run, the same functional name appeared
in multiple lettered sub-crates (`kernel-gga-3a/src/<func>/`,
`kernel-gga-3b/src/<func>/`, etc.) with DIFFERENT `.rs` files in each.
The bin-packers treated each (sub-crate, functional) pair as independent,
producing wrong layouts.

### `tools/resplit_gga.py` (cb85f3a5)

| Bug | Fix |
|-----|-----|
| `delete_old_subcrates()` regex `^kernel-gga-\d+$` missed lettered sub-crates | Broadened to `^kernel-gga-\d+[a-p]?$` |
| `update_workspace()` strip regex missed lettered | Same broadening |
| `get_functional_line_counts()` read only from `kernel-gga/src/` (empty post-split) | Auto-runs `gather_into_aggregator()` first when sub-crates exist |
| `gather_into_aggregator()` (NEW) | Per-file merge: copies every `.rs` file (except `mod.rs`) from each sub-crate's `<func>/` into a unified `kernel-gga/src/<func>/`. Aborts loud on filename clobber (non-disjoint splits indicate a bug worth investigating). Synthesises a unified `mod.rs` from the merged file set. |
| No `--dry-run` | Added; runs end-to-end accounting without filesystem mutation |

### `tools/rebatch_mgga.py` (5708902a)

| Bug | Fix |
|-----|-----|
| `get_functional_sizes()` produced one record per (sub-crate, functional) pair → bin-pack treated dupes as separate entries | Now merges by name; sums lines (excluding `mod.rs`) across all source crates; tracks the source list for materialization |
| Materialization copied whole functional directories from a single source crate (lossy for lettered splits) | Per-file merge into staging; mod.rs synthesised from union of file basenames |
| Generated Cargo.toml carried stale `[profile.dev]` and `[profile.test]` sections (commit 4be5c995 removed those project-wide) | Dropped from template |
| Tool only PRINTED what the user should paste into `kernel-mgga/Cargo.toml`, `kernel-mgga/src/lib.rs`, and workspace root | Auto-updates all three (`update_facade()`, `update_workspace()`) |
