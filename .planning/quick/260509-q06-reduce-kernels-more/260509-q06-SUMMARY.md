## Pre-req fix (commit `beddd1b0`)

`tools/resplit_gga.py:create_subcrate()` used `shutil.copytree`,
contradicting its own docstring ("Move (`mv`) each functional directory
from kernel-gga/src/ into the new sub-crate's src/"). After q05's repack,
every per-functional dir existed in BOTH:

- `crates/kernel-gga/src/<func>/` (orphan, copied during create_subcrate)
- `crates/kernel-gga-1..8/src/<func>/` (live)

131 functionals × 13.8 files avg = 1810 duplicate files / 137 MB on disk.
`crates/kernel-gga/src/lib.rs` doesn't `pub mod` the orphans (only
`pub use`s the sub-crates), so they were dead from rustc's view but
bloated git history and would have tripped the merge guard in
`gather_into_aggregator()` on the next `--repack`.

Fix: switch `create_subcrate()` to `shutil.move`, `git rm -r` the orphan
trees (verified byte-identical to peers before deletion).
