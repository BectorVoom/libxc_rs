# Quick Task 260509-q08 — Reduce GGA / MGGA per-file size

## Goal

Roll back q06's consolidation of GGA and MGGA sub-crates so each crate holds
fewer lines of generated CubeCL code. Smaller per-crate volume reduces peak
proc-macro RAM and unblocks `cargo check` / `cargo build` on RAM-constrained
machines (jobs ≤ 2).

User intent (confirmed): **smaller files = more sub-crates** = LOWER thresholds.
Trigger is preventive (no observed build failure since q06).

## Layout (target = q05 recovery point per q06 SUMMARY)

| Family | q06 (now) | q08 target | Threshold | Notes |
|--------|----------:|-----------:|----------:|-------|
| GGA  | 5 sub-crates @ ≤500K | **8 sub-crates** @ ≤300K | `--bin-limit 300000` | All bins ≤ 300K (no solo-oversized; largest single GGA functional ~277K). |
| MGGA | 8 sub-crates @ ≤600K | **14 sub-crates** @ ≤300K | `--target-max 300000` | 4 solo-oversized bins are unavoidable: `mgga_c_revtpss` (551K), `mgga_c_tpssloc` (556K), `mgga_c_rmggac` (367K), `mgga_c_tpss` (331K). q05 layout shipped with this. |
| LDA  | 1 sub-crate @ 187K   | **2 sub-crates** @ ≤100K | `--target-max=100000`   | Added mid-task at user request after GGA/MGGA landed. q04 recovery layout: 87K + 100K. |

## Task list

### T1 — GGA resplit (commit 1)

**Action:** `python3 tools/resplit_gga.py --bin-limit 300000`

What the script auto-handles:
- Recreate `crates/kernels/gga-1..8/` directories with regenerated `Cargo.toml` + `src/lib.rs`.
- `mv` per-functional source dirs from old `gga-1..5/` into new `gga-1..8/` (q06 already fixed the `shutil.move` orphan-leak bug).
- Rewrite `crates/kernels/gga/Cargo.toml` deps (5 → 8 sub-crate path entries).
- Rewrite `crates/kernels/gga/src/lib.rs` re-exports (`batch1..batch8`).
- Update root `Cargo.toml` `default-members` (replace `gga-1..5` lines with `gga-1..8`).

**Verify:**
- `find crates/kernels/gga/src -maxdepth 1 -type f -name '*.rs'` shows only `lib.rs` (no orphan func dirs).
- `ls crates/kernels/gga-*` lists exactly `gga`, `gga-1..gga-8`.
- `grep -c '^pub use libxc_kernel_gga_' crates/kernels/gga/src/lib.rs` = 8.

**Files:** `crates/kernels/gga/**`, `crates/kernels/gga-{1..8}/**` (new), `crates/kernels/gga-{1..5}/**` (some deleted — old gga-1..5 are recreated, no extras to remove since 8 ≥ 5), `Cargo.toml` (workspace `default-members`).

**Commit:** `refactor(quick-260509-q08): GGA 5→8 sub-crates via --bin-limit 300000`
