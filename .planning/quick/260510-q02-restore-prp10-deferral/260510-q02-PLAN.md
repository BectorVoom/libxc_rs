# Quick Task 260510-q02: Restore mgga_x_2d_prp10 module deferral

## Goal

Restore the documented deferral of `mgga_x_2d_prp10` so cargo build of `libxc-kernel-mgga-12` does not fail with missing-Bessel errors.

## Investigation

`cargo build -p libxc-kernel-mgga-12` produced 40+ E0425/E0433 errors for `xc_bessel_I0` / `xc_bessel_I1` across the prp10 functional's vxc/fxc/kxc/lxc files. These functions are not implemented in `libxc-kernel-math/`. Phase 04-04-SUMMARY.md (line 120) documents that the prp10 module was originally commented out in its lib.rs for exactly this reason. The comment-out was silently lost when q06/q08 regenerated `mgga-N/src/lib.rs` from `os.listdir(src_dir)`.

## Fix

### Task A — Re-comment-out prp10 module declaration

**files:** `crates/kernels/mgga-12/src/lib.rs`
**action:** change `pub mod mgga_x_2d_prp10;` → commented with the deferred reason and a re-enable note. Keep the on-disk source files intact (they will be referenced again once Bessel I0/I1 land in `kernel-math`).
**verify:** `git diff` shows a single one-line semantic change; `grep "mgga_x_2d_prp10" crates/kernels/mgga-12/src/lib.rs` returns the commented-out line; no other references touched.
**done:** committed.

### Task B — Document and update STATE.md

**files:** `.planning/quick/260510-q02-restore-prp10-deferral/260510-q02-SUMMARY.md`, `.planning/STATE.md`
**action:** SUMMARY captures the regression mechanism so the next splitter regen knows to preserve the comment-out (or so a tool fix in `rebatch_mgga.py` / `split_oversized_mgga.py` is scoped properly). STATE.md row + Last activity bumped.
**verify:** STATE.md row links the q02 directory; SUMMARY.md status frontmatter says complete.
**done:** atomic doc commit.

## Out of scope

- Implementing Bessel I0/I1 as `#[cube]` functions in `kernel-math` — that's a translation-unblock, not a build fix.
- Adding prp10 to `DEFERRED_MGGA_FUNCTIONALS` — that list is scoped to root-finder-blocked functionals (the test asserts `len == 6`); conflating reasons would muddy the type. The prp10 deferral surface lives in `mgga-12/src/lib.rs` (build-level) and `src/model/mgga_functional.rs` (api-level).
- Hardening the splitter tools (`rebatch_mgga.py`, `split_oversized_mgga.py`) to read a "deferred modules" allow-list when regenerating `lib.rs` — separate tooling task.
- Cargo build verification — RAM-constrained-machine rule defers to user out-of-band.
