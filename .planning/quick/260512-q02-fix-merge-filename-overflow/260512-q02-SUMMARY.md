## Smallvec / serde-1.0.228 blocker (NOT this task)

Fresh `cargo check -p libxc-kernel-mgga-14 -j 1`:

```
error[E0220]: associated type `Error` not found for `B`
  --> .../smallvec-1.15.1/src/lib.rs:1961:65
fn visit_seq<B>(self, mut seq: B) -> Result<Self::Value, B::Error>
```

This is a registry-wide compatibility issue between **smallvec 1.15.1**
and **serde 1.0.228** when smallvec's `serde` feature is enabled (which
hyper transitively enables). Peak RSS at failure was 372 MB — no RAM
issue. Suggested workarounds:

  1. Pin serde in `Cargo.toml`:
     `serde = { version = "=1.0.227", ... }`
  2. Wait for smallvec 1.15.2 to land
  3. Disable hyper's serde feature where possible

Once unblocked, `cargo check -p libxc-kernel-mgga-14` should reach the
kernel proc-macro expansion and exercise the new split kernels.
